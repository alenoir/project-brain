# Schemas — v0.2 target

This directory will contain the JSON Schemas that formalize [spec chapter 09](../spec/v0.1/09-metadata.md):

- `brain-manifest.schema.json` — `brain.yaml`
- `knowledge-item.schema.json` — the Metadata Block
- `context-manifest.schema.json` — `context/manifest.yaml`
- `context-pack.schema.json` — pack files

Deliberately empty at v0.1: schemas formalize a spec, they must not precede it (see [`ROADMAP.md`](../ROADMAP.md)). Until v0.2, the prose of chapter 09 is the reference.
