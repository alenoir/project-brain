# Agents: this project has a brain

Machine-readable project knowledge lives in [`.brain/`](.brain/) (Project Brain standard, spec 0.1 — which this repository happens to define).

- Start with `.brain/brain.yaml`, then its `entry` (`.brain/overview.md`).
- Current state and pending decisions: `.brain/state/now.md`.
- The normative text of the standard is `spec/v0.1/`; the constitution is `PRINCIPLES.md`.
- This repository contains **no code** and never hosts any real project's memory.
- Write your findings only to `.brain/candidates/` — never elsewhere in `.brain/`.

Note: this brain is currently unverified (all items `candidate`) — the founding
content awaits human verification, exactly as the standard requires (Principle P4).
