# project-brain

**What.** The home of the Project Brain standard: an open specification for
turning any Git repository into a governed, portable project brain readable by
humans and exploitable by AI agents. This repository is Layer 1 only — the
contract. Tools live elsewhere; real projects' brains live with those projects.

**Why it exists.** Project knowledge (decisions, constraints, state, domain
rules) has no standard home; agents rebuild context every session and vendors
are answering with proprietary memories. A vendor-neutral, repo-native standard
inverts that: the project owns its brain; tools merely visit. See `VISION.md`.

**What it refuses to be.** Not a wiki, not a RAG, not a SaaS, not a framework,
and never the host of any real project's memory (Principle P1).

**Key vocabulary.** *Brain*, *Knowledge Item*, *Authority*, *Provenance*,
*Verification*, *Context Pack* — full vocabulary in `GLOSSARY.md`.

**Where to go next.** Current state: `state/now.md`. The constitution:
`PRINCIPLES.md`. The normative text: `spec/v0.1/`. Known limits: `CRITIQUE.md`.
