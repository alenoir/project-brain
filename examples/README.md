# Examples

Complete, fictional brains illustrating the specification. **Every project here is invented** — this repository never hosts a real project's memory (Principle P1).

| Example | Illustrates |
|---|---|
| [`acme-billing/`](acme-billing/) | A Level 2→3 brain for a fictional invoicing service: manifest, overview, state, decisions, rules & invariants, an agent-written candidate, context manifest and packs. |

Planned for v0.2: a Level 1 minimal brain (two files), a monorepo umbrella brain, and a corpus of *deliberately invalid* brains as schema/conformance fixtures.

Examples are non-normative. Where an example and the spec disagree, the spec wins and the example has a bug.
